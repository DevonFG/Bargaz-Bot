BargazBot is a passion project by Devon Finney-Gaitan (RandomWolf08).

This project is meant to help support creators of any kind by acting
as a multi-purpose bot with lots of customization and options.

The bot currently has unlimited access to YouTube, Twitch, and Kick
notifications with all customization options that could be thought 
of, a reliable status update feature, an update feature to announce
changes to all servers, and more!

This bot is open to any feedback, whether it be the want for a new
feature or a bug, and it can be shared in the BargazBot feedback 
channel in "The Wolf's Den" Discord server.

Please note that all features are subject to change, and that more
features will likely be added over time.

Also, please note that this bot includes code generated by AI in the
interest of time.
